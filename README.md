A premium, highly-animated personal portfolio and resume website designed to showcase a journey of **innovation** and **code**. This project focuses on high-end aesthetics, smooth interactions, and a professional print-ready CV experience.

---

## 🚀 Key Features

### 🎨 Visual Excellence
- **Cinematic Entrance:** High-impact Hero section with split-text animations and spring-based physics.
- **Magnetic Interactions:** Buttons and elements that realistically attract to the cursor for a tactile feel.
- **Glassmorphism:** Modern UI layers with backdrop blurs and subtle border glows.
- **Custom Cursor:** A specialized interactive cursor that reacts to the environment.
- **Animated Backgrounds:** Floating gradients and mesh patterns that bring the page to life.

### 🛠️ Technical Mastery
- **Next.js 15 App Router:** Built using the latest server-side rendering and routing paradigms.
- **Tailwind CSS v4:** Leveraging the newest CSS-first configuration and utility engine.
- **Agentic AI Ready:** Showcasing skills in Python-based autonomous agent development.
- **Performance Optimized:** Lazy loading, optimized images, and minimal bundle size.

### 📄 Professional Utility
- **One-Click CV Export:** A dedicated "Download CV" feature that utilizes professional CSS print media queries to transform the website into a clean, traditional resume.
- **Project Showcase:** Interactive 3D tilt cards for showcasing featured works.

## 📦 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/shamanaz12/shama-resume.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
